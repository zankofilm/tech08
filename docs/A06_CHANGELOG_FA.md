# تغییرات A06 نسبت به A05-FA01

- `MainActivity.java`: رابط بومی دفتر نمره، انتخاب کلاس/نیم‌سال، فهرست فشرده دانش‌آموزان، مشاهده فعالیت‌ها، فرم ثبت/ویرایش فعالیت، تأیید نمره مستمر، خواندن/ثبت پایانی.
- `GradebookRules.java`: اعتبارسنجی نمرات فارسی/عربی و محاسبه سقف نمره پایانی.
- `app/build.gradle`: افزایش نسخه آزمایشی به ۰٫۶ (کد نسخه ۹).
- `.github/workflows/build-debug-apk.yml`: نام بسته A06 و اجرای تست قواعد نمره.
- `tools/TestGradebookRules.java`: ۱۷ تست Java بدون نیاز به SDK.
- `tools/verify_a06.py`: ۱۶ کنترل ایستای پروژه.

هیچ تغییری در سرور، دیتابیس یا پوسته وب رخ نداده است.
