# مدرسه‌یار معلم A05 — بازنویسی بومی آزمایشی

**این پروژه از صفر با اجزای بومی Android نوشته شده، نه WebView.** ظاهر تمام صفحات ارائه‌شده اندرویدی است و HTML سایت در هیچ بخش بارگذاری نمی‌شود. `MainActivity.java` شامل صفحه ورود، داشبورد، منوی اصلی و صفحات داده است؛ `SchoolApi.java` اتصال HTTPS به سرویس واقعی را انجام می‌دهد.

**هدف نهایی:** برابری کامل با تمام امکانات مجاز پنل وب معلم. این نسخه نقطه شروع واقعی است، نه ادعای تکمیل همه امکانات.

## قابلیت‌های واقعی پیاده‌سازی‌شده در سورس

| بخش | وضعیت در A05 |
|---|---|
| ورود اختصاصی اندروید از `/app/api/staff/login` و محدودیت نقش معلم | پیاده‌سازی؛ نیازمند تست روی هاست |
| تغییر اجباری رمز اولیه و تغییر رمز معمولی | پیاده‌سازی مطابق API |
| داشبورد اختصاصی آبی/سفید با نام معلم و برنامه روز | پیاده‌سازی مطابق `/app/api/teacher/dashboard` |
| کلاس‌ها، تخصیص‌ها، لیست دانش‌آموزان | پیاده‌سازی از `/app/api/teacher/workspace` |
| حضور و غیاب با تیک‌زدن دانش‌آموزان و تأیید قبل از ثبت | پیاده‌سازی طبق API رسمی؛ فقط در بازه مجاز |
| برنامه هفتگی و دانش‌آموزان من | پیاده‌سازی خواندنی |
| فهرست آزمون‌ها و نتایج ثبت‌شده | پیاده‌سازی خواندنی؛ **نه دفتر نمره کامل** |
| ورود با اثر انگشت و Android Keystore | پیاده‌سازی در سورس، نیازمند تست بیومتریک روی گوشی |
| خروج از نشست و درخواست ابطال در سرور | پیاده‌سازی |
| تمام فرم‌های بانک سؤال، ساخت آزمون، تصحیح، تکالیف، دفتر نمره | **هنوز منتقل نشده‌اند؛ در A05 نباید کامل تلقی شوند** |
| فایل‌ها، چاپ و اعلان‌های اندرویدی | **هنوز منتقل نشده‌اند** |

## نصب در GitHub

1. محتوای این ZIP را **در یک مخزن یا شاخه آزمایشی** قرار بده. توصیه می‌شود برای جلوگیری از حذف نسخه سالم A04، مخزن جدید `madreseyar-teacher-native-test` یا شاخه `native-a05-test` بسازی.
2. وارد Actions شو و `Build Native Teacher Android APK` را اجرا کن.
3. اگر Build موفق شد، فایل `Madreseyar-Teacher-A05-Native-Debug-APK` را در بخش Artifacts دریافت کن.
4. APK را روی گوشی آزمایشی نصب کن. اگر با امضای Debug قبلی تداخل داشت، از تنظیمات APK قبلی حذف یا قبل از حذف از اطلاعات غیرقابل‌بازگشت آن اطمینان حاصل کن. حساب سرور حذف نمی‌شود.

## سیاست فنی و امنیتی

- `SchoolApi.BASE` به `https://scooljavanrood.ir/app` متصل می‌شود؛ اگر دامنه/پیشوند هاست تغییر کرد این ثابت باید اصلاح شود.
- ورود و نقش و مجوزها همچنان در سرور کنترل می‌شوند؛ اندروید نباید اجازه‌های اضافی ایجاد کند.
- رمز عبور در Android ذخیره نمی‌شود؛ نشست فقط پس از تأیید بیومتریک قوی با کلید AES-GCM در Android Keystore ذخیره می‌شود.
- فایل‌های سرور، پایگاه داده، `data/` و نسخه مادر دست‌نخورده‌اند.
- اطلاعات آزمایشی ساختگی به‌عنوان نمره یا حضور واقعی نمایش داده نمی‌شوند.
- این نسخه **نه APK کامپایل‌شده و نه نسخه تأییدشده گوشی** است. Gradle/Android SDK در محیط تهیه سورس موجود نیست، پس موفقیت واقعی را GitHub Actions و تست عملی تعیین می‌کند.

## مسیر تکمیل ۱۰۰٪ امکانات

A06: دفتر نمره و بارم مستمر/پایانی + فعالیت‌های روزانه؛ A07: مرکز تکالیف و بارگذاری فایل؛ A08: بانک سؤال و آزمون‌ساز؛ A09: تصحیح، گزارش‌ها، پیام‌ها و اعلان‌ها؛ A10: تست رگرسیون تمام جریان‌های معلم. برابری کامل فقط با تست اجرای تمام عملیات و تأیید کاربر قابل اعلام است.

از حساب معلم آزمایشی استفاده کن. هنگام ارسال اسکرین‌شات، اطلاعات شناسایی دانش‌آموزان را بپوشان.
