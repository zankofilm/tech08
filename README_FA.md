# مدرسه‌یار معلم — نسخه A06 بومی فارسی (آزمایشی)

**بر پایه آخرین نسخه A05-FA01، نه پوسته وب A04.** تمام رابط‌ها اندرویدی هستند و هیچ WebView در برنامه وجود ندارد.

## چه چیزهایی در A06 جدید است؟

- دفتر نمره واقعی با انتخاب کلاس، درس و نیم‌سال اول/دوم
- خواندن اطلاعات دفتر نمره از `GET /api/staff/gradebook` با توکن رسمی معلم
- فهرست فشرده دانش‌آموزان؛ نمای جداگانه جزئیات و سوابق هر نفر
- ثبت فعالیت دستی (تکلیف، پرسش شفاهی، پروژه، مشارکت یا دسته‌های تعریف‌شده توسط مدیر) و ویرایش رکورد خود از API دفتر نمره
- تأیید نمره نهایی مستمر با سقف تنظیم‌شده و تأیید دوباره پیش از ارسال
- مشاهده نمره پایانی ثبت‌شده و ثبت پایانی با سقف `۲۰ - بارم مستمر`
- حالت فقط مشاهده وقتی دفتر قفل شده یا تنظیمات بارم مدیریت فعال نشده باشد
- حفظ نتایج آزمون‌ها در بخش نمرات، و حفظ کلاس‌ها، حضور، برنامه، ورود فارسی و اثر انگشت A05

## مرزهای مهم

**مهم:** APK هنوز در این محیط کامپایل یا روی گوشی تست نشده است. تست‌ها ایستا و مبتنی بر منطق Java هستند. برای استفاده عملی ابتدا در GitHub Actions فایل APK آزمایشی بسازید، سپس تنها با معلم و دانش‌آموزان آزمایشی کار کنید.

- این نسخه آزمون‌ساز، بانک سؤال و مرکز تکالیف را هنوز به‌صورت بومی پیاده‌سازی نکرده است. برای جلوگیری از ارائه دکمه بی‌عمل، این مسیرها تا آماده‌شدن API و پیاده‌سازی واقعی اضافه نشده‌اند.
- API سرور مرجع اصلی مجوزها، قفل‌ها، کارنامه منتشرشده و سقف پایانی است؛ اعتبارسنجی اندروید جای مجوزهای سرور نیست.
- تا زمانی که بارم دفتر نمره توسط مدیر ذخیره و فعال نشده، اپ اجازه ثبت نمره دستی یا نهایی نمی‌دهد.
- میانگین محاسباتی از ۲۰، معادل «نمره مستمر تأییدشده» نیست؛ برای جلوگیری از اشتباه، این دو عنوان عمداً متمایز نمایش داده می‌شوند.
- سرور هنگام انتشار کارنامه امکان تغییر نمره را می‌بندد و در صورت رد عملیات پیام مناسب نشان داده می‌شود.
- در هیچ مرحله‌ای داده زنده یا رمز عبور داخل ZIP قرار داده نشده است.

## روش نصب GitHub

1. در مخزن جداگانه مخصوص اپ بومی، محتوای ZIP را در ریشه مخزن قرار دهید (فایل‌ها در یک پوشه اضافی نباشند).
2. به Actions ← Build Native Teacher Android APK بروید و Run workflow را اجرا کنید.
3. اگر Build موفق بود از Artifacts نسخه `Madreseyar-Teacher-A06-Native-Debug-APK` را دریافت کنید.
4. روی گوشی آزمایشی نصب کنید. با حساب آزمایشی معلم وارد شوید، تب «نمرات» را باز کنید و کلاس و نیم‌سال را انتخاب کنید.
5. تست‌های `docs/QA_A06_FA.md` را انجام دهید و پیش از استفاده واقعی نتیجه را گزارش کنید.

اگر فقط قصد ارتقا از A05-FA01 دارید، بسته `A06_PATCH_FROM_FA01.zip` و مسیرهای `INSTALL/` را با حفظ ساختار GitHub جایگزین کنید؛ فایل‌های `ROLLBACK_TO_FA01/` برای بازگشت هستند. **هاست اصلی یا `server.mjs` تغییر نمی‌کند.**

## راهنمای پشتیبانی

اگر GitHub Actions قرمز شد، گزارش `Show compiler errors` را بفرستید. موفقیت تست‌های موجود به معنی بی‌نیازی از ساخت APK نیست.
