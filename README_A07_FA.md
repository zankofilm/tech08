# مدرسه‌یار معلم — A07 | کارنامه تفصیلی آزمون‌ها

**نسخه آزمایشی بومی و فارسی اندروید؛ مبنا: A06 (دفتر نمره واقعی).**

## تغییرات

با انتخاب «نمرات ← نتایج آزمون‌ها ← نمایش نتایج ثبت‌شده»، فهرست دانش‌آموزانی که نتیجه دارند باز می‌شود. برای هر دانش‌آموز دکمه «مشاهده کارنامه تفصیلی و پاسخ سؤال‌ها» اضافه شده است.

با لمس دکمه، اپ به‌صورت مستقیم از API موجود زیر گزارش نهایی را درخواست می‌کند:

`GET /api/teacher/continuous-p11?studentId=...&examId=...`

API موجود مدرسه‌یار مجوز معلم و تخصیص درس/کلاس را بررسی می‌کند. فقط نتایج آزمون‌های نهایی و **نمره تشریحی منتشرشده** برگردانده می‌شوند. این پچ هیچ endpoint جدید، نوشتن جدید یا تغییر دیتابیس ندارد.

صفحه بومی تفصیلی نشان می‌دهد: کل سؤال‌ها، پاسخ‌داده‌شده، درست، نادرست، بی‌پاسخ، نیمه‌صحیح، نمره واقعی از سرور، متن هر سؤال، گزینه و پاسخ انتخابی (برای تستی)، پاسخ صحیح/معیار و بازخورد در صورت موجودبودن در API. پاسخ فایل‌دار فقط با متن توضیح داده می‌شود، نه افشای فایل بدون مجوز.

**تفسیر شمارش:** «پاسخ‌داده‌شده» = درست + غلط + نیمه‌صحیح؛ «بی‌پاسخ» جداست. در تشریحی، پاسخِ با بخشی از امتیاز، نیمه‌صحیح است و به‌عنوان «غلط کامل» شمرده نمی‌شود. تعداد از آرایه واقعی questions گرفته می‌شود، نه عدد ساختگی.

آیکون رسمی تأییدشده‌ی آبی مدرسه‌یار معلم در اندازه‌های استاندارد `mipmap` گنجانده شده است. طراحی و منطق بومی ورود، اثر انگشت، حضور و غیاب، دفتر نمره A06 و سایر صفحات حفظ شده‌اند.

## نصب با GitHub

**گزینه اول:** محتویات ZIP پروژه کامل را در یک مخزن آزمایشی مجزا یا شاخه آزمایشی قرار بده و Actions → `Build Native Teacher Android APK` → `Run workflow` را اجرا کن.

**گزینه دوم:** اگر سورس فعلی دقیقاً A06 است، محتویات پوشه `INSTALL/` در ZIP پچ را با همان ساختار در مخزن جایگزین کن؛ برای فایل‌های جدید هم پوشه بساز. Commit کن و GitHub Actions را اجرا کن.

**بازگشت:** محتویات `ROLLBACK_TO_A06/` در ZIP پچ را جایگزین کن؛ سپس فایل‌های اضافی درج‌شده در `DELETE_ON_ROLLBACK.txt` را حذف کن. اطلاعات هاست/دیتابیس تغییری نمی‌کنند.

## تست واقعی پیشنهادی

۱. با حساب آزمایشی معلم وارد شو؛ از تب نمرات بخش «نتایج آزمون‌ها» را باز کن.
۲. یک آزمون تستی نهایی با دانش‌آموز آزمایشی انتخاب کن؛ روی «مشاهده کارنامه تفصیلی» بزن.
۳. آمار درست، غلط و بی‌پاسخ را با برگه واقعی دانش‌آموز و پنل وب مقایسه کن. در صورت وجود نمره، آن هم باید یکسان باشد.
۴. برای آزمون تشریحی تصحیح و منتشرشده، بخش «نیمه‌صحیح» و توضیح معلم را بررسی کن.
۵. آزمون بدون نتیجه نهایی را امتحان کن؛ نباید جزئیات ساختگی نمایش دهد.
۶. حساب معلم دوم با کلاس متفاوت نباید بتواند گزارش دانش‌آموز غیرمجاز را بگیرد (پاسخ 403).
۷. منوی اصلی، ورود با اثر انگشت، دفتر نمره A06 و بارگذاری صفحات دیگر را هم بررسی کن.
۸. از نتایج تست اسکرین‌شات بدون نام کامل/کدملی دانش‌آموز ارسال کن.

## محدودیت‌های تأیید

تست‌های Java (قواعد شمارش)، تست قرارداد API با داده ساختگی و تست ایستای سورس انجام شده‌اند. **APK در این محیط ساخته و روی گوشی نصب نشده**؛ سازگاری واقعی و مقایسه با رکوردهای مدرسه باید در GitHub و گوشی تست شود.
