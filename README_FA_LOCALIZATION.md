# مدرسه‌یار معلم — اصلاح زبان فارسی A05-FA01

این یک اصلاح **آزمایشی** روی سورس بومی A05 است. تمام صفحه‌های موجود در A05 از ابتدا با Viewهای اندروید ساخته شده‌اند، نه با WebView.

## چه چیزهایی اصلاح شد؟
- زبان مستقل برنامه «فارسی (ایران)» شد؛ لازم نیست زبان کل گوشی فارسی باشد.
- جهت پیش‌فرض عناصر برنامه راست‌به‌چپ است.
- اعداد **در نمایش** فارسی هستند؛ کد ملی، رمز و شناسه‌هایی که به API ارسال می‌شوند بدون تغییر باقی می‌مانند.
- عنوان نسخه در صفحه ورود و متن راهنمای اثر انگشت به فارسی تغییر یافت.
- وضعیت‌های رایج آزمون‌ها و پیام‌های شناخته‌شده شبکه/دسترسی به متن قابل‌فهم فارسی تبدیل شدند.
- منابع استاندارد زبان برنامه و فایل زبان‌ها اضافه شد.

## محدودیت‌ها
- صفحه‌های مستقل هنوز در مرحله A05 هستند؛ این اصلاح ماژول‌های آزمون‌ساز، تکالیف یا دفتر نمره کامل را اضافه نمی‌کند.
- متن نوشته‌شده در سمت سرور، نام‌های خاص و اطلاعات ثبت‌شده توسط مدرسه بدون دست‌کاری حفظ می‌شود؛ بخشی از این اطلاعات ممکن است انگلیسی باشد.
- پنجره‌های سیستمی اندروید، مانند تأیید خود حسگر اثر انگشت، بسته به زبان و نسخه سیستم‌عامل ممکن است از زبان گوشی پیروی کنند.
- کنترل‌های ایستای فایل‌ها به معنی تأیید موفق APK نیست؛ GitHub Actions باید بیلد بگیرد و تست روی گوشی انجام شود.

## ارتقا در GitHub
1. در مخزن A05، فایل‌های پوشه INSTALL بسته پچ را با مسیر اصلی خود جایگزین کن.
2. نسخه جدید را Commit کن و GitHub Actions را اجرا کن.
3. APK ساخته‌شده را نصب کن؛ نسخه‌کد از ۷ به ۸ افزایش یافته تا بتواند نسخه قبلی را ارتقا دهد (در صورت یکسان بودن کلید امضا).
4. صفحه ورود، انتخاب اثر انگشت، منوهای پایین، کلاس‌ها، نتایج آزمون و پیام‌های خطا را بررسی کن.

این پچ هیچ فایلی از هاست و دیتابیس را تغییر نمی‌دهد.
